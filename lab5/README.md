## Классы

| Класс | Назначение |
|---|---|
| `Product` | Название, категория, цена и счётчик живых экземпляров |
| `BinarySearchTree` | Бинарное дерево, ключом служит цена |
| `Node` | Внутренний узел дерева, скрытый в `binary_search_tree.cpp` |
| `ProductSelector` | Абстрактный критерий отбора |
| `PriceBelowSelector` | Проверка `price < limit` |
| `AllProductsSelector` | Критерий, принимающий все записи |
| `Selection` | Динамический массив слабых ссылок на товары |

В `Product` операторы `<` и `==` сравнивают только цену без `eps`. Повторная цена в дерево не добавляется. Цена должна быть конечной и неотрицательной. Для поиска и удаления создаётся эталон `Product(price)` с пустыми названием и категорией. Конструкторы увеличивают статический счётчик живых товаров, деструктор уменьшает его.

## Владение и копирование

Каждый `Node` владеет дочерними узлами через `std::unique_ptr<Node>` и записью через `std::shared_ptr<Product>`. Узел скрыт в `.cpp`, поэтому конструкторы перемещения, присваивание и деструктор дерева определены там, где тип узла полный.

Дерево не копируется, но перемещается; исходное дерево после перемещения пустое. Поддеревья уничтожаются автоматически. Поиск возвращает `std::weak_ptr<Product>`, не продлевая время жизни записи.

`Selection` хранит массив `std::weak_ptr<Product>`, которым владеет `std::unique_ptr` на массив. Копирование создаёт независимый массив слабых ссылок, перемещение передаёт владение массивом. Выборка не владеет товарами. При удалении записи из дерева соответствующая ссылка в прежней выборке становится истёкшей. Доступ к товару выполняется только через `lock()`.

## Обход

`BinarySearchTree::select(const ProductSelector&) const` за один симметричный обход добавляет записи, удовлетворяющие критерию. Дерево не зависит от конкретного критерия и не изменяется. Время обхода `O(n)`, дополнительная память для рекурсии `O(h)`. Выборка сразу упорядочена по возрастанию цены. Массив выборки растёт удвоением вместимости.

При удалении узла без детей удаляется узел; при одном ребёнке переносится владение ребёнком; при двух используется преемник из правого поддерева. Дерево поддерживает симметричный и обратный обходы. Высота пустого дерева равна 0, листа равна 1.

Вывод записей содержит название, категорию и цену через пробел. Выборка печатает размер и записи по порядку, а истёкшие ссылки отмечает `[удалено]`.

## Сборка и тесты

В корневом `CMakeLists.txt` требуется `enable_testing()` и `add_subdirectory(lab5)`. Тестов Google Test ровно 14.

```bash
cmake -S . -B cmake-build-debug
cmake --build cmake-build-debug --target lab5_main lab5_tests
./cmake-build-debug/lab5/lab5_main
./cmake-build-debug/lab5/lab5_tests
```

CMake включает `-Wall`, `-Wextra`, `-Wpedantic`, AddressSanitizer при компиляции и линковке. Отсутствие утечек проверяется также счётчиком `Product::aliveCount()`.
